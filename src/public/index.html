Gateway de Integración (Booking Bus)

Base URL:

Importante:
Este es un solo Gateway para todas las APIs de integración del Booking Bus. Los ejemplos usan el paquete CUEN-CAJAS como referencia.

1) GET Paquetes

GET /api/v2/paquetes

Devuelve el listado de paquetes disponibles.

curl -X GET "/api/v2/paquetes"

2) POST Disponibilidad

POST /api/v2/paquetes/availability

Body (ejemplo):

{
  "idPaquete": "CUEN-CAJAS",
  "fechaInicio": "2026-01-09T00:20:30.576Z",
  "personas": 1
}
curl -X POST "/api/v2/paquetes/availability" \
  -H "Content-Type: application/json" \
  -d '{"idPaquete":"CUEN-CAJAS","fechaInicio":"2026-01-09T00:20:30.576Z","personas":1}'

Respuesta esperada: { "disponible": true/false, "cupos_disponibles": number }

3) POST Usuario Externo

POST /api/v2/paquetes/usuarios/externo

Crea/actualiza el usuario externo por correo (upsert).

Body (ejemplo):

{
  "correo": "patito+ext@gmail.com",
  "nombre": "Patito",
  "apellido": "Perez"
}
curl -X POST "/api/v2/paquetes/usuarios/externo" \
  -H "Content-Type: application/json" \
  -d '{"correo":"patito+ext@gmail.com","nombre":"Patito","apellido":"Perez"}'

Respuesta esperada: { "id_usuario": number, "correo": "..." }

4) POST Pre-reserva (Hold)

POST /api/v2/paquetes/pre-reserva

Crea un hold (pre-reserva) temporal para confirmar luego con /reserva.

Body (ejemplo):

{
  "idPaquete": "CUEN-CAJAS",
  "fechaInicio": "2026-01-09T00:24:26.935Z",
  "turistas": [
    {
      "nombre": "Patito",
      "apellido": "Perez",
      "fechaNacimiento": "1999-01-01T00:00:00.000Z",
      "tipoIdentificacion": "CI",
      "identificacion": "1234567890",
      "tipo": "adulto"
    }
  ],
  "duracionHoldSegundos": 1800
}
curl -X POST "/api/v2/paquetes/pre-reserva" \
  -H "Content-Type: application/json" \
  -d '{"idPaquete":"CUEN-CAJAS","fechaInicio":"2026-01-09T00:24:26.935Z","turistas":[{"nombre":"Patito","apellido":"Perez","fechaNacimiento":"1999-01-01T00:00:00.000Z","tipoIdentificacion":"CI","identificacion":"1234567890","tipo":"adulto"}],"duracionHoldSegundos":1800}'

Respuesta esperada: { "id_hold": "HOLD-XXXXXX", "expiraEn": "..." }

5) POST Reserva (Confirmar Hold)

POST /api/v2/paquetes/reserva

Confirma el hold y crea la reserva definitiva.

Body (ejemplo):

{
  "idPaquete": "CUEN-CAJAS",
  "idHold": "HOLD-XXXXXX",
  "correo": "patito@gmail.com",
  "turistas": [
    {
      "nombre": "Patito",
      "apellido": "Perez",
      "fechaNacimiento": "1999-01-01T00:00:00.000Z",
      "tipoIdentificacion": "CI",
      "identificacion": "1234567890",
      "tipo": "adulto"
    }
  ]
}
curl -X POST "/api/v2/paquetes/reserva" \
  -H "Content-Type: application/json" \
  -d '{"idPaquete":"CUEN-CAJAS","idHold":"HOLD-XXXXXX","correo":"patito@gmail.com","turistas":[{"nombre":"Patito","apellido":"Perez","fechaNacimiento":"1999-01-01T00:00:00.000Z","tipoIdentificacion":"CI","identificacion":"1234567890","tipo":"adulto"}]}'

Respuesta esperada: { "id_reserva": "RV-...", "reserva_id_interno": number }

6) POST Facturas (Invoices)

POST /api/v2/paquetes/invoices

Registra el pago y devuelve el enlace de factura.

Body (ejemplo):

{
  "idReserva": "RV-1238-LAJ123",
  "correo": "patito@gmail.com",
  "nombre": "Patito",
  "valor": 25.50
}
curl -X POST "/api/v2/paquetes/invoices" \
  -H "Content-Type: application/json" \
  -d '{"idReserva":"RV-1238-LAJ123","correo":"patito@gmail.com","nombre":"Patito","valor":25.50}'

Respuesta esperada: { "url_factura": "https://.../admin/facturas/..." }

7) GET Datos de Reserva

GET /api/v2/paquetes/:id/reserva

Consulta los detalles de la reserva por su código.

curl -X GET "/api/v2/paquetes/RV-1238-LAJ123/reserva"

8) POST Cancelar

POST /api/v2/paquetes/cancelar

Cancela una reserva por su código.

Body (ejemplo):

{
  "idReserva": "RV-1238-LAJ123"
}
curl -X POST "/api/v2/paquetes/cancelar" \
  -H "Content-Type: application/json" \
  -d '{"idReserva":"RV-1238-LAJ123"}'

Respuesta esperada: { "exito": true/false, "valor_pagado": number }

Si abres este link, estás usando un solo Gateway para toda la integración.
