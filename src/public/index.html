Gateway de Integración (Booking Bus)

Base URL:

1) GET Paquetes

GET /api/v2/paquetes

Devuelve el listado de paquetes.

curl -X GET "/api/v2/paquetes"

2) POST Disponibilidad

POST /api/v2/paquetes/availability

Body (ejemplo):

{
  "idPaquete": "1",
  "fechaInicio": "2026-01-09T00:20:30.576Z",
  "personas": 10
}
curl -X POST "/api/v2/paquetes/availability" \
  -H "Content-Type: application/json" \
  -d '{"idPaquete":"1","fechaInicio":"2026-01-09T00:20:30.576Z","personas":10}'

3) POST Usuario Externo

POST /api/v2/paquetes/usuarios/externo

Body (ejemplo):

{
  "correo": "patito@gmail.com",
  "nombre": "patito",
  "apellido": "patito"
}
curl -X POST "/api/v2/paquetes/usuarios/externo" \
  -H "Content-Type: application/json" \
  -d '{"correo":"patito@gmail.com","nombre":"patito","apellido":"patito"}'

4) POST Pre-reserva (Hold)

POST /api/v2/paquetes/pre-reserva

Body (ejemplo):

{
  "idPaquete": "1",
  "bookingUserId": "patito@gmail.com",
  "correo": "patito@gmail.com",
  "fechaInicio": "2026-01-09T00:24:26.935Z",
  "turistas": [
    {
      "nombre": "patito",
      "apellido": "patito",
      "fechaNacimiento": "2026-01-09T00:24:26.935Z",
      "tipoIdentificacion": "CI",
      "identificacion": "1234567890"
    }
  ],
  "duracionHoldSegundos": 300
}

5) POST Reserva

POST /api/v2/paquetes/reserva

Body (ejemplo):

{
  "idPaquete": "1",
  "idHold": "HOLD-123412",
  "correo": "patito@gmail.com",
  "metodoPago": "Efectivo",
  "turistas": [
    {
      "nombre": "patito",
      "apellido": "patito",
      "fechaNacimiento": "2026-01-09T00:27:41.837Z",
      "tipoIdentificacion": "CI",
      "identificacion": "1234567890"
    }
  ],
  "paymentStatus": "TRUE"
}

6) POST Facturas

POST /api/v2/paquetes/invoices

Body (ejemplo):

{
  "idReserva": "RV-1238-LAJ123",
  "correo": "patito@gmail.com",
  "nombre": "patito",
  "tipoIdentificacion": "CI",
  "identificacion": "1234567890",
  "valor": 25.50
}

7) GET Datos de Reserva

GET /api/v2/paquetes/:id/reserva 
curl -X GET "/api/v2/paquetes/RV-1238-LAJ123/reserva"

8) POST Cancelar

POST /api/v2/paquetes/cancelar

Body (ejemplo):

{
  "id_reserva": "RV-1238-LAJ123"
}

Si abres este link, estás usando un solo Gateway para toda la integración.
